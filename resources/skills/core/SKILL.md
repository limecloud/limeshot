# Core Production Rules

- Gather the intended deliverable, source rights, target market, format, and budget before planning work.
- Only select registered workflows and capabilities. Report an unavailable capability instead of improvising a provider request.
- Treat user approval, a cost quote, and consent for a face or voice as separate gates.
- Read run state and artifacts through structured tools. Do not write files, call network services, or run media commands directly.
- Preserve provenance: every proposed output must point to its source assets and approved plan.
