## 退出条件

1. `v0.4.0` 本地候选通过 `verify:app-version`、`resource:check`、`typecheck`、`test:contracts`、完整 Vitest 与 macOS Gate B。
2. `v0.4.0` GitHub Actions 的 Windows x64 job 在 `windows-2022` 上完成真实 Electron Gate B、Squirrel 构建和包内资源校验。
3. `v0.4.0` 正式 Release 同时包含 macOS arm64 DMG/ZIP、Windows x64 Setup EXE/NuGet/RELEASES 和覆盖全部资产的 SHA-256 清单。
4. `v0.4.0` 发版前完成文档与架构确认；不得引入第二套 Agent runtime、Rust Codex proxy、PATH fallback 或生产 mock。

## 发布引用约束

`v0.3.0` 已是公开 tag/Release，本计划不得删除、移动或重建该 tag，也不得覆盖其 Release 资产。Windows 支持只允许进入新的 `v0.4.0` tag。

## Windows 切片当时的本地验证

- `npm run verify:app-version`：通过。
- `npm run resource:check`：通过，Codex manifest 同时要求 `darwin-arm64` 与 `win32-x64`。
- `npm run typecheck`：通过。
- `npm run test:contracts`：2 个文件、8 项测试通过。
- `npm test`：18 个文件、69 项测试通过。
- `npm run electron:build`：通过。
- `npm run verify:gui-smoke`：Gate B 通过，Codex `0.145.0`、12 次 provider request、history/projection/interrupt 与业务媒体链证据通过。
- `cargo check --target x86_64-pc-windows-msvc -p business-server`：本机缺 Windows C SDK，`libsqlite3-sys` 编译 SQLite 时找不到 `stdlib.h`；必须由下一版本的 `windows-2022` job 原生验证。
- Release workflow YAML：Ruby YAML parser 通过；本机未安装 `actionlint` 与 PowerShell，Windows step 语法等待 Actions 验证。

`v0.4.0` 完整候选已于 `2026-07-29` 重新通过 `verify:local`、19 个文件 97 项 Vitest、41 项 Rust 测试与 Codex `0.145.0` / Business protocol v5 的 13-request Gate B；Windows 原生构建与 Squirrel 资产仍等待 `v0.4.0` Actions 验证。
