## 签名与风险

- macOS 使用 ad-hoc 签名，尚未配置 Developer ID 和 notarization。
- GitHub repository 当前没有 Windows signing secrets；workflow 将明确生成 unsigned Squirrel 资产。
- workflow 只在 Windows certificate 与 password 同时存在时启用签名，缺一项会 fail closed。
- tag 默认不可改写。本次首次 Release 从未公开且没有资产；用户在收到公开 tag 冲突风险后明确要求保留 `v0.4.0` 并授权精确重建。此例外只适用于本次失败候选，不形成后续惯例。
